# Метки триажа

Навыки используют пять канонических ролей триажа. Этот файл сопоставляет роли с фактическими метками, используемыми в трекере задач репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                      |
| ------------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`            | `needs-triage`        | Требуется оценка задачи сопровождающим        |
| `needs-info`              | `needs-info`          | Ожидается дополнительная информация от автора |
| `ready-for-agent`         | `ready-for-agent`     | Задача полностью описана и готова для агента  |
| `ready-for-human`         | `ready-for-human`     | Требуется реализация человеком                |
| `wontfix`                 | `wontfix`             | Задача не будет выполнена                     |

Когда навык упоминает роль, например «применить метку готовности для автономного агента», используйте соответствующую метку из этой таблицы.

При необходимости отредактируйте правый столбец, чтобы он соответствовал фактической системе меток проекта.
